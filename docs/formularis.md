# Formularis

El formulari està a `src/app/components/form/form.component.ts`.

- Utilitza `ReactiveFormsModule`.
- El camp `terme` té un mínim de 3 caràcters (minLength).
- El validador asíncron espera 400 ms i comprova si hi ha resultats.
- Es poden netejar els camps i recuperar cerques de l'historial.
