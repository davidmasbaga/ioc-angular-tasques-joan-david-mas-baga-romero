# Gestor de Tasques

## Autor/a

Joan David Mas-Bagà Romero

## Descripció

Aplicació web desenvolupada amb Angular per gestionar i organitzar tasques del meu cicle formatiu

## Versions utilitzades

* Node.js 24
* Angular 22
* Angular CLI 22
* Git

## Com crear i executar el projecte

Instal·lar les dependències:

```bash
npm install o npm i
```

Executar l'aplicació en mode desenvolupament:

```bash
ng serve
```
o també podem utilitzar 
```bash
npm run start
```

L'aplicació estarà disponible a:

```text
http://localhost:4200
```

## Estat de l'EAC1

Projecte base Angular creat i configurat amb routing, SCSS i SSR desactivat.
S'ha preparat l'estructura inicial de carpetes, s'ha personalitzat la pàgina principal amb variables amb un component a ``app.component.ts`` i s'ha comprovat el funcionament del hot reload.
